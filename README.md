# Gerenciador de Tarefas

## Funcionalidades principais:
- **Autenticação Simples:** Tela de login e cadastro
- **Agenda Interativa:** Calendário completo para organização diária das tarefas.
- **Gestão de Tarefas:** Adição de tarefas com horário (formato 24h) e descrição.
- **Ordenação Automática:** Tarefas pendentes aparecem primeiro, seguidas pelas concluídas.
- **Resumo Mensal:** Visualização dedicada de todas as tarefas do mês, separadas por status e data.
